# 🗳️ DemocracyOS | Advanced Civic Intelligence System

**DemocracyOS** is a high-performance, interactive civic assistant built to empower citizens with data-driven transparency. Designed for the Promptwars competition, it delivers a premium experience within a strict **8MB repository constraint**.

---

## 🚀 Vision
To bridge the gap between complex constitutional processes and the average voter through **Autonomous Intelligence**, **Real-time Synthesis**, and **Massive Scale Data Visualization**.

## 🌟 Premium Features
- **🛸 Command Center**: A glassmorphism-inspired landing page with real-time system metrics.
- **📊 Historical Intelligence Engine**: Analyzes a **5.5MB / 100,000+ record** synthetic dataset using high-performance Plotly visualizations.
- **🤖 AI Analyst**: An autonomous agent with multi-tool reasoning (NewsAPI integration, Database querying, and Knowledge Base retrieval).
- **🗺️ Interactive Mission Protocol**: A high-fidelity slider-based walkthrough of the 6 phases of democracy.
- **🎓 Democracy Quiz**: A gamified assessment tool to test and improve civic knowledge.
- **✅ Voter Eligibility Protocol**: A secure, logic-driven checker for participation readiness.

## 🛠️ Technical Stack
- **Frontend**: Streamlit (Custom CSS/Glassmorphism)
- **Analytics**: Pandas & Plotly Express (High-performance rendering)
- **Intelligence**: NewsAPI integration with autonomous agent routing logic.
- **Database**: 5.7MB Optimized CSV (Historical Turnout Data).

## 📦 Constraints & Optimization
- **Size**: < 8MB (Currently ~7.4MB including Git history).
- **Performance**: Zero-lag interactivity despite large dataset handling.
- **UX**: Dark-mode primary design with premium typography (Inter).

## 🏗️ Deployment
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Launch the intelligence system:
   ```bash
   streamlit run app.py
   ```
