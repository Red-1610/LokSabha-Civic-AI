# 🗳️ Civic Guide & Election Assistant

An interactive, lightweight Streamlit application designed to educate citizens about the democratic election process in India. This app features interactive timelines, rule explanations, live news fetching, and a voter eligibility checker.

## 🌟 Features
*   **🗺️ Interactive Election Timeline:** A step-by-step visual slider taking users through the 6 phases of an election (Announcement to Results).
*   **📚 Process & Rules:** Simple explanations of complex topics like the Model Code of Conduct, EVMs, and NOTA.
*   **✅ Voter Eligibility Checker:** An interactive tool for users to verify if they meet the criteria to vote.
*   **📰 Live India Election News:** Real-time news fetched via NewsAPI to keep voters updated directly in the sidebar.

## 🚀 How to Run Locally

### Prerequisites
* Python 3.8+ installed.

### Installation
1. Clone this repository.
2. Install the required dependencies:
```bash
pip install -r requirements.txt
```
3. Run the Streamlit application:
```bash
streamlit run app.py
```

## 📦 Size & Constraints
This project was built with a strict < 10MB repository size constraint. It leverages pure Python and Streamlit native components without relying on heavy external image assets or models.
